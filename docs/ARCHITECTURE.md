# CHC V2 architecture

V2 extends the existing `chc` package with `chc/v2`; it does not replace the detector, trained correction model, old FLAN reasoner, old experiments, or original application routes. The old experimental release remains available separately.

The collection boundary accepts a real HotpotQA question and its annotation-linked source passages. The frozen backend generates explicit short factual claims and a short final answer. These are observable artifacts, not a window into private model reasoning. Strict JSON parsing checks field sets, source IDs, unique claim IDs, earlier-only dependencies and nonempty statements. An optional grammar backend constrains token format. A separate citation-alignment backend can assign a missing citation through an explicitly recorded retrieval step that can find support, contradiction or insufficient evidence. It records the original rejection and all assigned-source provenance. It does not rewrite claims or turn malformed dependencies into valid ones.

A supported two-claim prefix enters the controlled mutation stage. The NLI judge checks originals and mutations, retaining unsupported/uncertain candidates for review. A valid automatic contradiction candidate is chosen by a question-hash rotation over eligible error families before any downstream continuation is observed. The collector generates clean, corrupted, each singleton verification and joint verification continuations with matched question/evidence/seed. Restoring the exact original prefix is an analysis-only diagnostic, not a deployable verification action.

The NLI evaluator separately checks newly generated claims. The evaluator alone receives the reference answer for final exact match. `DecisionState` stores only current question, claim text, possible edges, evidence and predicted features. Targets are joined after `node_features` has extracted serving inputs. V2 adds a named signed-utility supervision field to the existing training graph function; V1 behavior remains the default.

The collector stores raw outputs, errors, citation provenance, automatic judgments, proposals, accepted changes and actual continuations. Analysis derives metrics from these records. Training is gated on signal counts; no synthetic examples enter research performance tables. The web service can inspect recorded examples with no model loading, or perform actual live generation using supplied evidence.

Cache hits reuse actual saved outputs. Logical verification budgets are replay costs, not new model-execution counts. Cached generation latency is the original execution measurement rather than the time to replay a policy.

Source attachment and factual acceptance are separate operations. Filtering uncited continuations by support would censor the errors the benchmark intends to measure; the corrected collector retains contradicted and unresolved continuations. Clean starting prefixes still require support. A selected mutation also receives a pre-outcome cross-source support veto: if another source supports it, or it repeats another supported prefix assertion, it is rejected. Invalid mutated graphs are logged rather than crashing collection. The same veto is applied to earlier records before fitting, while raw outputs are preserved.

The policy graph adds optional source-entity bridge hypotheses from available passages, separate from model-declared links and measured effects. A declaration-only retrained ablation tests that feature recipe. Conservative factual-unit extraction splits explicit sentence boundaries and shared-subject verb conjunctions; residual compounds remain flagged for review. Labels and graph nodes therefore have an explicit parent/unit mapping rather than a claim of perfect semantic atomicity.

Main propagation tables use a disclosed complete-case cohort. A separate all-primary-input answer analysis extracts actual parseable final-answer fields even when a trace failed validation, and reports answer availability and trace validity independently. Missing answers count as operational failures, never as factual contradictions. Per-unit evaluability is reported to expose changes in the unknown denominator.
