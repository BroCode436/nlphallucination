# Dataset methodology

HotpotQA supplies real multi-hop questions, evidence documents, supporting annotations and reference answers. The cached official training prefix contains 500 questions. Source passages contain up to six annotated supporting sentences with distinct document coverage, original titles and sentence indices. This is a controlled oracle-evidence condition, not an end-to-end retrieval benchmark. Dataset provenance links to https://huggingface.co/datasets/hotpotqa/hotpot_qa and attribution is retained. HotpotQA is CC-BY-SA-4.0.

Backend development uses official training rows 440:460. Debugging uses 460:480. The configured larger pilot uses training rows 200:400, tuning rows 400:440, and official validation rows 510:570 as an untouched final test slice. The historical V1 test used official validation rows 10:510, so the new final slice avoids that observed test set. The CLI records exact question IDs before collection. A `--limit` run truncates each split and must be labeled a smaller exploratory experiment. Question IDs must be disjoint; shared document titles are reported, not hidden. These are bounded slices, not representative population sampling.

The raw generated trace must validate before admission. The explicit source-alignment alternative preserves raw failure records and changes only missing citation metadata. Clean prefix claims must be automatically supported. This eligibility filter reduces coverage and changes the evaluated population. Raw attempts, rejection reasons and final eligible question counts must always accompany accuracy.

Ten mutation families have implementations conditional on explicit prerequisites: entity substitution, numeric offsets, date offsets, asymmetric relation reversal, explicit negation, citation misattribution, appended unsupported conclusion, exact arithmetic error, entity disambiguation, and multi-hop composition substitution. A candidate is not a gold error. The primary automatic challenge set requires supported original plus contradicted mutation from the NLI proxy. Other cases remain in `corruption_candidates.jsonl` with human review pending. Missing arithmetic/relation prerequisites produce no eligible example, not fabricated coverage. An unsupported conclusion can be unknown rather than false; provenance errors can leave factual text true.

All selected eligible neutral and harmful outcomes remain. No outcomes determine which candidates are retained. A round-robin hash rule selects families before generation. The resulting controlled challenge distribution is distinct from natural hallucination prevalence. The natural-distribution evaluation is the separately sampled RAGTruth detector test. No human-validated label set has been claimed. A blank worksheet and separate machine key support future blinded review.

RAGTruth uses existing processed train/validation/test CSVs. Detection samples retain the natural class distribution with seed 42. Source-ID overlap, duplicate claim/evidence rows, missing evidence and positive prevalence are audited. Calibration and threshold selection consume validation labels only. No detector fine-tuning is claimed in V2 unless a separately recorded training run exists.

The initial pilot encountered a still-true entity swap: both people were writers. Its unchanged factual meaning was supported by a second source. The protocol migration records the pre-outcome support veto and graph-rejection fix. Every earlier selected corruption is rechecked with the same rule; the original JSONL remains unchanged. This is input-label quality control, not selection by intervention gain.

Primary eligibility additionally checks conservatively extracted clean factual units. All atomic-scored records, including exclusions, are retained separately from episodes_primary.jsonl. Neither automated support nor contradiction is human gold. Ordinary dataset source overlap, shared corruption templates, and possible pretraining exposure remain limitations. Human worksheets and imported reviewer labels occupy separate files. No completed human-review count is asserted.
