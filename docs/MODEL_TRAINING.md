# Model training and detector investigation

The historical FLAN-T5-small backend is retained. Qwen2.5-1.5B-Instruct is evaluated using real local FP16 inference on the RTX 4050. The official card is https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct . A 1.54B-parameter model needs approximately 3.1 GB for FP16 weights plus activations and KV cache. Actual memory, structured-output yield, evidence support, tokens and runtime determine feasibility; larger size alone does not establish improvement. The current 2048-token input cap rejects oversized input, and outputs are capped at 280 tokens. Sampling temperature is 0.6 and top-p is 0.9. Language-model weights remain frozen.

The new evidence checker is cross-encoder/nli-deberta-v3-xsmall (https://huggingface.co/cross-encoder/nli-deberta-v3-xsmall), trained on SNLI/MultiNLI according to its official card. Its configured order is checked: contradiction, entailment, neutral. It is a standard existing NLI model, not a new CHC detector architecture. Sentence alignment selects up to three source sentences by visible lexical overlap; evidence-only truncation at 384 tokens preserves the claim. Missing evidence remains unreviewed, neutral remains insufficient, and high-confidence scores are automatic proxies requiring human validation.

Detection comparisons isolate original full-document DistilBERT-128, aligned DistilBERT-128, aligned DistilBERT-384, NLI contradiction and NLI non-entailment. Validation-only Platt scaling uses regularized logistic regression on score log-odds; validation F1 selects thresholds. Test reports precision, recall, F1, average precision PR-AUC, confusion matrices, Brier, ECE and reliability bins on uniform natural samples. Calibration fitted for binary RAGTruth labels is not presented as calibrated three-way HotpotQA truth; the serving calibrated probability remains null for that domain.

The tabular intervention model reuses histogram gradient boosting with a predeclared 18-configuration validation grid over leaf counts (3,7,15), minimum leaf size (3,10), and L2 (1,5,20), with 80 iterations. It has 14 pre-action features: risk, risk entropy proxy, descendants, depth, distance to final, evidence relevance, estimated cost, text length, number flag, negation flag, position, in-degree, out-degree, final-node flag. Missing targets are masked. Signed utility labels can be negative and neutral labels remain in fitting. Zero-benefit and training-mean predictors are explicit controls.

The reused directed GNN encodes [N,14] node features into [N,32] states. Each of two rounds concatenates self, incoming-neighbor mean and outgoing-neighbor mean into [N,96], then projects to [N,32]. A scalar head returns one benefit per node. Final placeholders and missing targets are masked. Training uses MSE, AdamW, learning rate .002, weight decay .01, 25 epochs, batch 16, accumulation 2, norm clipping 1, AMP on CUDA, training-only normalization, and best validation checkpoint selection. Optimizer/scaler/RNG states are retained in last checkpoints by the existing trainer. CPU fallback paths are preserved.

The semantic predictor uses frozen NLI-backbone mean-pooled embeddings, not an assumed optimal sentence embedding model. The padding mask excludes pad states from averaging. Question, current claim and aligned evidence are embedded before labels join. Concatenated semantic and numerical features enter a standardized Ridge regressor; alpha is selected from .1, 1, 10, 100 on validation only. This is a lightweight semantic baseline. A hybrid semantic-graph model is deferred until simpler models show a clear unmet limitation.

Before graph/semantic training, the predeclared gate requires at least 50 eligible training questions and 20 nonzero action targets. If this fails, those models are implemented but not reported as trained. A small exploratory tabular comparison may still run if train and validation targets exist. Multiple training seeds are 42,43,44. Ranking performance and positive/negative average precision are reported where labels permit. Ranking loss, class reweighting, or benefit-balanced sampling are not claimed implemented merely because discussed; sparse data must first justify those experiments.

Boosting gives each training question equal total sample weight and chooses mean question-validation MSE. The central final-only control uses exactly the richer target's measurable-candidate mask. A separate full-coverage final-only model and the legacy regressor retrained on the new data remain stronger supervision controls. The original V1 graph architecture is retained for the matched final-only graph control; original checkpoints are also evaluated as explicitly labeled direct transfer.

The source-bridge graph recipe is fixed before final-test evaluation. It adds a possible ordered link when one cited passage mentions the other passage's entity. Confidence .35 is heuristic, not causal probability. The tabular declaration-only ablation retains the original graph. The semantic Ridge model has matched without-embedding and without-graph-column variants.

The conservative complexity screen requires 50 eligible training questions and 20 nonzero targets. An explicitly requested low-signal diagnostic mode is also available, and its use is recorded; it does not establish statistical power. The measured pilot passed the original count gate. Three training seeds were actually used. The current collection uses one continuation seed, 101; training-seed variation is different from generation-seed replication.

Completed model reuse requires an identical train/validation input digest, training recipe hashes, seeds and configuration, plus existing checkpoint files. A logger-only seed-field collision interrupted orchestration after the first GNN saved; partial artifacts were backed up and a documented metadata migration allowed checkpoint resume. No training objective or model parameter was changed by that fix.
